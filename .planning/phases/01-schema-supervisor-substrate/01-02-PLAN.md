<objective>
Build the `holt-supervisor` wedge — the v0.1 substrate that makes Claude Code's statusLine never silently fail, never block, and always degrade to last-known-good on slow invocations.

**Purpose:** This crate owns process supervision for the entire workspace. It is the single chokepoint (D-09) where `Stdio::piped()` × 3 is enforced before `wrap(ProcessGroup::leader())` — C1 hardened in code so future contributors can't accidentally inherit the parent TTY (macOS SIGTTIN trap) by spawning children outside this function. It also owns the LKG cache, the `timings.jsonl` writer, the `breaches.log` writer, and the H3 killpg fallback (when setpgid hits EPERM under sandboxed parents on macOS).

**Output:**
1. `Supervisor::wrap_and_run(program, args, opts) -> SupervisorOutcome` — the only spawn site.
2. LKG cache read/write at `~/.cache/holt/lkg/<sid>.json` (using `holt_schemas::atomic_write` from plan 01 + the `LkgEntry` type).
3. `timings.jsonl` and `breaches.log` writers with 5MB / `.1` rotation; both write-only (C6 — render path never reads them; verified by plan 03's render-path test).
4. Five integration tests proving: passthrough works, timeout kills the whole process group with no orphans, LKG round-trips correctly, jsonl rotation triggers at 5MB, and the chokepoint static-audit holds.

**This plan delivers requirements:** CORE-02 (timings.jsonl), CORE-03 (LKG cache), CORE-04 (timeout + killpg + EPERM fallback), CORE-05 (Stdio::piped × 3 before wrap), CORE-06 (breaches.log).
</objective>

    ### Step 1.5 — `src/supervisor.rs` (THE CHOKEPOINT)

    Per RESEARCH Pattern 1 + RESEARCH §"Open Questions #1" recommendation (mpsc + thread, no extra dep). The single `.wrap(ProcessGroup::leader())` call site in the workspace lives here.

    ```rust
    //! D-09 chokepoint: `wrap_and_run` is the ONLY supervised-spawn site.
    //!
    //! C1 INVARIANT: stdin/stdout/stderr are piped BEFORE `wrap(ProcessGroup::leader())`.
    //! Adding a second `.wrap(ProcessGroup::leader())` call site anywhere in this crate
    //! is an audit hazard — `tests/chokepoint_audit.rs` will fail the build.
    //!
    //! Source: process-wrap v9.1.0 docs.rs (verified 2026-04-28).
    //!         https://docs.rs/process-wrap/9.1.0/process_wrap/

    use std::io::{Read, Write};
    use std::process::Stdio;
    use std::sync::mpsc;
    use std::thread;
    use std::time::Instant;

    use holt_schemas::{LkgEntry, atomic_write};
    use process_wrap::std::{CommandWrap, ProcessGroup};

    use crate::breaches::append_breach;
    use crate::lkg::write_lkg;
    use crate::options::{BreachKind, SupervisorOptions, SupervisorOutcome};
    use crate::paths;
    use crate::timings::append_timings;

    pub fn wrap_and_run(
        program: &str,
        args: &[&str],
        opts: SupervisorOptions,
    ) -> SupervisorOutcome {
        let started = Instant::now();

        // Build the command. C1: pipe ALL THREE stdio streams BEFORE wrap.
        // SIGTTIN avoidance — inheriting parent TTY in a backgrounded process group →
        // kernel sends SIGTTIN → child stops, looks like a hang.
        // (PITFALLS H3 — verified failure mode: openai/codex#8690, elixir-lang/elixir#15036)
        let mut wrap = CommandWrap::with_new(program, |c| {
            for a in args {
                c.arg(a);
            }
            c.stdin(Stdio::piped())
                .stdout(Stdio::piped())
                .stderr(Stdio::piped());
        });

        #[cfg(unix)]
        {
            wrap.wrap(ProcessGroup::leader());
        }
        #[cfg(windows)]
        {
            wrap.wrap(process_wrap::std::JobObject);
        }

        let mut child = match wrap.spawn() {
            Ok(c) => c,
            Err(e) => {
                let dur_ms = started.elapsed().as_millis() as u64;
                let outcome = SupervisorOutcome::Breach {
                    kind: BreachKind::SpawnFail,
                    exit_code: None,
                    duration_ms: dur_ms,
                    stderr_excerpt: format!("spawn failed: {e}"),
                };
                let _ = append_breach(
                    &opts.cache_root,
                    BreachKind::SpawnFail,
                    &opts.stdin_bytes,
                    format!("spawn failed: {e}").as_bytes(),
                    None,
                );
                let _ = append_timings_for(&opts, dur_ms, None, b"spawn failed");
                return outcome;
            }
        };

        // Capture pgid (= child PID since we spawned as group leader) for kill fallback.
        #[cfg(unix)]
        let pgid: i32 = child.id() as i32;

        // Pipe CC stdin to child stdin (best-effort; ignore broken-pipe).
        if !opts.stdin_bytes.is_empty() {
            if let Some(stdin) = child.stdin().take() {
                let bytes = opts.stdin_bytes.clone();
                // Move stdin into a thread so we don't deadlock if the child reads slowly.
                thread::spawn(move || {
                    let mut s = stdin;
                    let _ = s.write_all(&bytes);
                });
            }
        }

        // Take stdout/stderr handles BEFORE the wait thread moves the child.
        let stdout_handle = child.stdout().take();
        let stderr_handle = child.stderr().take();

        // Spawn drainers so the child doesn't block on full pipes.
        let stdout_thread = stdout_handle.map(|mut s| {
            thread::spawn(move || {
                let mut buf = Vec::with_capacity(4096);
                let _ = s.read_to_end(&mut buf);
                buf
            })
        });
        let stderr_thread = stderr_handle.map(|mut s| {
            thread::spawn(move || {
                let mut buf = Vec::with_capacity(4096);
                let _ = s.read_to_end(&mut buf);
                buf
            })
        });

        // Wait with deadline. Use mpsc + thread per RESEARCH §"Open Questions #1".
        let (tx, rx) = mpsc::channel();
        thread::spawn(move || {
            let res = child.wait();
            let _ = tx.send(res);
        });

        match rx.recv_timeout(opts.timeout) {
            Ok(Ok(status)) => {
                // Child exited within deadline. Drain stdout/stderr.
                let stdout_bytes = stdout_thread.and_then(|t| t.join().ok()).unwrap_or_default();
                let stderr_bytes = stderr_thread.and_then(|t| t.join().ok()).unwrap_or_default();

                let dur_ms = started.elapsed().as_millis() as u64;
                let exit_code = status.code().unwrap_or(-1);
                let stdout_str = String::from_utf8_lossy(&stdout_bytes).into_owned();

                // On exit 0: update LKG cache via D-07 atomic_write.
                if exit_code == 0 {
                    let entry = LkgEntry {
                        schema_version: LkgEntry::SCHEMA_VERSION,
                        stdout: stdout_str.clone(),
                        exit_code,
                        captured_at: jiff::Timestamp::now().to_string(),
                        duration_ms: dur_ms,
                    };
                    let _ = write_lkg(&opts.cache_root, &opts.session_id, &entry);
                }

                // Always append a timings.jsonl entry (CORE-02).
                let _ = append_timings_for(&opts, dur_ms, Some(exit_code), &stderr_bytes);

                SupervisorOutcome::Ok {
                    stdout: stdout_str,
                    exit_code,
                    duration_ms: dur_ms,
                }
            }
            Ok(Err(e)) => {
                let dur_ms = started.elapsed().as_millis() as u64;
                let _ = append_breach(
                    &opts.cache_root,
                    BreachKind::SpawnFail,
                    &opts.stdin_bytes,
                    format!("wait error: {e}").as_bytes(),
                    None,
                );
                let _ = append_timings_for(&opts, dur_ms, None, b"wait failed");
                SupervisorOutcome::Breach {
                    kind: BreachKind::SpawnFail,
                    exit_code: None,
                    duration_ms: dur_ms,
                    stderr_excerpt: format!("wait error: {e}"),
                }
            }
            Err(_) => {
                // TIMEOUT — kill the whole process group.
                #[cfg(unix)]
                {
                    let _ = crate::kill::kill_process_group(pgid);
                }
                // On Windows, the JobObject takes the children when our parent process exits;
                // for v0.1 we accept a small race where wedged Windows children may linger
                // briefly. Trigger to harden: ≥1 Windows-tagged "leftover process" issue.

                // Drain whatever stdout/stderr we got before the kill.
                let stderr_bytes = stderr_thread.and_then(|t| t.join().ok()).unwrap_or_default();
                let stderr_excerpt = String::from_utf8_lossy(
                    &stderr_bytes[..stderr_bytes.len().min(4096)],
                )
                .into_owned();
                let dur_ms = started.elapsed().as_millis() as u64;

                let _ = append_breach(
                    &opts.cache_root,
                    BreachKind::Timeout,
                    &opts.stdin_bytes,
                    &stderr_bytes,
                    None,
                );
                let _ = append_timings_for(&opts, dur_ms, None, &stderr_bytes);

                SupervisorOutcome::Breach {
                    kind: BreachKind::Timeout,
                    exit_code: None,
                    duration_ms: dur_ms,
                    stderr_excerpt,
                }
            }
        }
    }

    /// Build & append one timings.jsonl line. Best-effort.
    fn append_timings_for(
        opts: &SupervisorOptions,
        duration_ms: u64,
        exit_code: Option<i32>,
        stderr_bytes: &[u8],
    ) -> std::io::Result<()> {
        // CORE-02 schema: { ts, session_id, duration_ms, fork_count, exit_code, stderr_capture }.
        // fork_count is always 1 at v0.1 (we only fork the user's wrapped script directly).
        // True fork-count attribution is a v0.5 holt doctor concern.
        let line = serde_json::json!({
            "ts": jiff::Timestamp::now().to_string(),
            "session_id": &opts.session_id,
            "duration_ms": duration_ms,
            "fork_count": 1,
            "exit_code": exit_code,
            "stderr_capture": String::from_utf8_lossy(
                &stderr_bytes[..stderr_bytes.len().min(4096)],
            ),
        });
        let mut text = serde_json::to_string(&line).unwrap_or_else(|_| "{}".into());
        text.push('\n');
        append_timings(&opts.cache_root, &text)
    }
    ```

    ### Step 1.6 — `src/kill.rs` (H3 fallback)

    ```rust
    //! killpg + EPERM PPID-walk fallback (PITFALLS H3).
    //!
    //! On macOS, `setpgid` succeeds inside sandboxes (Cursor, some VS Code variants) but
    //! `killpg` may be denied silently against descendants. On Linux, scripts that exec
    //! a daemon may re-parent under PID 1 (init / systemd-launchd equivalent) and escape
    //! the original pgid. We fall back to walking `/proc/*/status` (Linux) or
    //! `libc::proc_listchildpids` (macOS) and SIGKILL'ing each known descendant.
    //!
    //! Best-effort: returns Ok(()) if at least the killpg itself succeeded; returns Err
    //! only if killpg fails AND the fallback failed to reap any descendants.

    #[cfg(unix)]
    pub fn kill_process_group(pgid: i32) -> std::io::Result<()> {
        use nix::sys::signal::{Signal, killpg};
        use nix::unistd::Pid;

        // Try killpg first.
        match killpg(Pid::from_raw(pgid), Signal::SIGKILL) {
            Ok(()) => Ok(()),
            Err(nix::errno::Errno::EPERM) => {
                // EPERM: sandbox / launchd-reparented; fall back to PPID-walk.
                ppid_walk_kill(pgid)
            }
            Err(e) => Err(std::io::Error::other(format!("killpg({pgid}) failed: {e}"))),
        }
    }

    #[cfg(unix)]
    #[cfg(target_os = "linux")]
    fn ppid_walk_kill(target_pgid: i32) -> std::io::Result<()> {
        use std::fs;
        use nix::sys::signal::{Signal, kill};
        use nix::unistd::Pid;

        // Walk /proc/*/status looking for any pid whose Pgid matches target_pgid.
        let entries = fs::read_dir("/proc")?;
        let mut killed_any = false;
        for entry in entries.flatten() {
            let name = entry.file_name();
            let Some(name_str) = name.to_str() else { continue };
            let Ok(pid) = name_str.parse::<i32>() else { continue };
            let status_path = entry.path().join("status");
            let Ok(status) = fs::read_to_string(&status_path) else { continue };
            for line in status.lines() {
                if let Some(rest) = line.strip_prefix("Pgid:") {
                    if rest.trim().parse::<i32>().ok() == Some(target_pgid) {
                        let _ = kill(Pid::from_raw(pid), Signal::SIGKILL);
                        killed_any = true;
                    }
                }
            }
        }
        if killed_any {
            Ok(())
        } else {
            Err(std::io::Error::other(
                "killpg EPERM and no /proc descendants matched target pgid",
            ))
        }
    }

    #[cfg(unix)]
    #[cfg(not(target_os = "linux"))]
    fn ppid_walk_kill(_target_pgid: i32) -> std::io::Result<()> {
        // macOS: libc::proc_listchildpids exists but requires libproc-sys; for v0.1 we
        // accept the EPERM-and-survive case on macOS and document it as a known limitation.
        // Trigger to harden: ≥1 macOS-tagged "killpg failed under sandbox" issue.
        Err(std::io::Error::other(
            "killpg EPERM on non-linux; libproc fallback deferred to post-v0.1",
        ))
    }
    ```

    ```rust
    //! `timings.jsonl` writer with 5MB / `.1` rotation (D-12).
    //!
    //! Rotation happens INSIDE the writer. Render path opens this file with O_APPEND for
    //! write — never for read. C6 enforced.

    use std::fs::{self, OpenOptions};
    use std::io::{self, Write};
    use std::path::Path;

    use crate::paths::timings_path;

    /// 5MB cap per D-12.
    pub const MAX_BYTES: u64 = 5 * 1024 * 1024;

    pub fn append_timings(cache_root: &Path, line: &str) -> io::Result<()> {
        let path = timings_path(cache_root);
        if let Some(parent) = path.parent() {
            fs::create_dir_all(parent)?;
        }
        append_jsonl(&path, line)
    }

    pub(crate) fn append_jsonl(path: &Path, line: &str) -> io::Result<()> {
        debug_assert!(line.ends_with('\n'), "caller must include trailing newline");

        if let Ok(meta) = fs::metadata(path) {
            if meta.len() + line.len() as u64 > MAX_BYTES {
                let mut backup = path.to_path_buf();
                let new_ext = match path.extension().and_then(|s| s.to_str()) {
                    Some(ext) => format!("{ext}.1"),
                    None => "1".into(),
                };
                backup.set_extension(new_ext);
                let _ = fs::rename(path, &backup);
            }
        }

        let mut f = OpenOptions::new().create(true).append(true).open(path)?;
        f.write_all(line.as_bytes())?;
        // Deliberately NO fsync per line — append-and-lose-on-crash is acceptable for
        // observability output. Different from D-07 (LKG / heartbeat durability).
        Ok(())
    }
    ```

    ```rust
    //! C1 chokepoint audit: there must be EXACTLY ONE call to
    //! `.wrap(ProcessGroup::leader())` in the entire holt-supervisor crate.
    //!
    //! Adding a second one anywhere bypasses the C1 invariant (always pipe stdio first)

    use std::fs;
    use std::path::Path;

    #[test]
    fn only_one_wrap_call_site_in_supervisor_crate() {
        let crate_src = Path::new(env!("CARGO_MANIFEST_DIR")).join("src");
        let mut total = 0_usize;

        for entry in walk(&crate_src) {
            if entry.extension().and_then(|s| s.to_str()) != Some("rs") {
                continue;
            }
            let text = fs::read_to_string(&entry).unwrap_or_default();

            // doesn't accidentally count. Note: we use `//` not `#`, so the standard
            // grep gate hygiene rule (filter '#' comments) doesn't apply directly —
            // instead we filter Rust line comments.

                .lines()
                .filter(|l| !l.trim_start().starts_with("//"))
                .map(|l| l.matches(".wrap(ProcessGroup::leader())").count())
                .sum();
            total += counted;
        }

        assert_eq!(
            total, 1,
            "C1 chokepoint violated: expected exactly 1 .wrap(ProcessGroup::leader()) call site \
             across crates/holt-supervisor/src/, found {total}. Every supervised spawn must go \
             through Supervisor::wrap_and_run."
        );
    }

    fn walk(dir: &Path) -> Vec<std::path::PathBuf> {
        let mut out = Vec::new();
        if let Ok(entries) = fs::read_dir(dir) {
            for e in entries.flatten() {
                let p = e.path();
                if p.is_dir() {
                    out.extend(walk(&p));
                } else {
                    out.push(p);
                }
            }
        }
        out
    }
    ```
