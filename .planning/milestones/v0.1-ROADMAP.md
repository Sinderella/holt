# Milestone v0.1 — Runtime hygiene wedge (the lovable MVP)

**Shipped:** 2026-04-29

## Key accomplishments

1. **`holt-schemas` keystone crate** with non-panicking `read_heartbeat()` reader contract, atomic `write` helper (same-dir tmp + fsync + rename), `Heartbeat` and `LkgEntry` types versioned at `schema_version: 1`. The keystone every other crate depends on; `#[non_exhaustive]` field shapes preserve API freedom for v0.5+.
2. **`holt-supervisor` runtime hygiene substrate** — single `process-wrap::ProcessGroup::leader()` chokepoint enforces stdio-piping (C1); LKG cache with sub-2ms render fall-through; killpg + Linux /proc PPID-walk fallback on EPERM; 5MB JSONL rotation for `timings.jsonl` + `breaches.log`.
3. **`holt-hooks` heartbeat write side** — defensive CC stdin parse with `#[serde(default)]` everywhere; 3-tier fallback path resolution (`$XDG_RUNTIME_DIR/holt/sessions/` → `$TMPDIR/holt-$UID/` → `~/.cache/holt/`); 1000× SIGKILL atomicity test asserts every observable file state parses cleanly.
4. **`holt install-hooks` JSONC-tolerant settings.json merger** — `jsonc-parser` 0.26 CST in-place edit preserves comments + key order; `fs2::FileExt::try_lock_exclusive()` with 200ms acquisition deadline; fsync-before-rename + `.holt.bak` backup; `--dry-run` and `--print` escape hatches; 50× concurrent stress + 200× SIGKILL atomicity verified.
5. **All 6 hard architectural constraints test-enforced.** C1 (stdio piping chokepoint), C2 (`holt-render` ⊥ `holt-supervisor`), C3 (settings.json mutation atomicity), C4 (JSONC confined to `holt-cli`), C5 (reader returns `Ok(None)` for any defect — never panics), C6 (render path never reads breaches/timings logs). Each constraint has at least one `cargo test` that fails on regression.
6. **Sub-20ms render-path budget verified.** `holt --self-bench` p95=0us; `holt --self-bench-hook PreToolUse` p95=5874us — both with 3× headroom under the 20ms gate. CI matrix runs both gates on every PR (Linux + macOS REQUIRED, Windows ALLOWED-FAILURE).
7. **Distribution stack ready: dist v0.31.0 + binstall.** Workspace scaffold via `dist init`; 4-target matrix (Linux x64, macOS x64+arm64, Windows x64); `--version` parity check (D-14) wired into release workflow; SHA-256 sidecars on every artifact; MSRV 1.87 / Edition 2024 build matrix gates regressions.
8. **One-shot bootstrap automation (Phase 4.1).** `tools/bootstrap-github.sh` collapses the 3 maintainer-side handoff steps (gh repo create + first push + label apply) into one idempotent call with `--dry-run` mode. Tag-push retained as a deliberate human ship decision.
