# Requirements: holt — v0.1 (archived)

**Defined:** 2026-04-28
**Shipped:** 2026-04-29
**Core Value:** Make Claude Code's statusLine never silently fail, never block input, and tell the user — through Nak — exactly what each of their sessions is doing.

**Outcome:** 27/28 satisfied, 1 deferred to v0.1.x. All hard constraints C1..C6 test-enforced at HEAD.

## v1 Requirements (final state)

### Core — shim wrapper + timing + cache + supervision

- [x] **CORE-01**: Shim binary wraps user's existing `statusLine.command` from `~/.claude/settings.json` and emits the wrapped script's stdout unchanged on the happy path
- [x] **CORE-02**: Per-fire timing log appended to `~/.cache/holt/timings.jsonl` with duration, fork count, exit code, and stderr capture for every wrapped invocation
- [x] **CORE-03**: Last-known-good TTL cache — render previous output instantly, recompute in background, replace on completion
- [x] **CORE-04**: Configurable timeout + clean Unix process-group kill via `process-wrap` v9.1.0 `ProcessGroup::leader()` (setpgid + killpg) — verifies `setpgid` return value and falls back to libproc PPID-walk + per-PID SIGKILL if EPERM
- [x] **CORE-05**: All spawned children pipe stdin/stdout/stderr (`Stdio::piped()` × 3) — never inherit parent TTY (SIGTTIN avoidance, hard constraint C1)
- [x] **CORE-06**: Breach log appended to `~/.cache/holt/breaches.log` with full context (env, stdin JSON, stderr) when timing exceeds configurable threshold
- [x] **CORE-07**: Sub-20ms cold-start overhead on Linux x86_64 and macOS arm64 — **VALIDATED**: `holt --self-bench` p95=0us on macOS arm64
- [x] **CORE-08**: Defensive stdin JSON parse — failures captured in breach log; render falls through to LKG cache; never bubbles errors to user
- [x] **CORE-09**: Render path never opens `breaches.log` or `timings.jsonl` for reading (C6) — **VALIDATED**: `tests/render_path_no_read.rs` strace-asserts on Linux + stub-replaced fs interface on macOS
- [x] **CORE-10**: `holt-render` has zero dep on `holt-supervisor` (C2) — **VALIDATED**: `tests/architecture_dag.rs` BFS over `cargo metadata`

### Hooks — heartbeat write + install UX

- [x] **HOOK-01**: Heartbeat hook subscribes to `PreToolUse`, `PostToolUse`, `Stop`, `Notification`, and `SessionStart` events; writes session JSON on every fire
- [x] **HOOK-02**: Heartbeat path = `$XDG_RUNTIME_DIR/holt/sessions/<sid>.json` (Linux), `$TMPDIR/holt-$UID/sessions/<sid>.json` (macOS), with layered fallback chain to `~/.cache/holt/sessions/`
- [x] **HOOK-03**: Atomic heartbeat write — same-dir tmp + `fsync(2)` + `rename(2)` (C5) — **VALIDATED**: 1000× SIGKILL atomicity stress test (`tests/sigkill_atomicity.rs`)
- [x] **HOOK-04**: Heartbeat populates `cwd_label` from `workspace.git_worktree` (CC v2.1.98+); **adjusted**: falls back to `cwd` basename only at v0.1 (the originally-specified `<repo>/<branch>` `git rev-parse` heuristic deferred to v1.0 because shelling out to git would violate D-15 sub-20ms budget)
- [x] **HOOK-05**: Heartbeat schema `schema_version: 1` per `docs/05-schemas.md` §1 — `pid`, `started`, `updated`, `cwd`, `cwd_label`, `mode`, `current_tool`, `blocked_on` (always null at v0.1), `last_assistant_at`, `model_display`
- [x] **HOOK-06**: Heartbeat embeds `writer_version` field for forward-compat
- [x] **HOOK-07**: `holt install-hooks` reads `~/.claude/settings.json`, merges holt's hook entries non-destructively, writes back atomically with `.holt.bak` backup
- [x] **HOOK-08**: `holt install-hooks --dry-run` prints diff; `--print` emits JSON snippet for manual paste; both exit 0 without mutating settings.json
- [x] **HOOK-09**: `holt install-hooks` acquires `fs2::FileExt::try_lock_exclusive()` for the entire read-merge-write window; fsync before rename (C3) — **VALIDATED**: 50× concurrent stress + 200× SIGKILL atomicity (`tests/install_hooks_concurrent.rs` + `install_hooks_sigkill.rs`)
- [x] **HOOK-10**: `holt install-hooks` round-trips JSONC (preserves comments + key order) — `jsonc-parser` v0.26+ CST in `holt-cli` only (C4) — **VALIDATED**: `tests/cli_dep_boundary.rs` confines `jsonc-parser` and `fs2` to `holt-cli`
- [x] **HOOK-11**: Reader (`holt-schemas::read_heartbeat`) treats stale-or-corrupt heartbeat as missing — never `unwrap()`, never panics (C5) — **VALIDATED**: 9-case `tests/reader_contract.rs`
