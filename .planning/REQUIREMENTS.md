# Requirements: holt

**Defined:** 2026-04-28
**Core Value:** Make Claude Code's statusLine never silently fail, never block input, and tell the user — through Nak — exactly what each of their sessions is doing.
**Current milestone:** **v0.1 — Runtime hygiene wedge** (the lovable MVP, target 3–4 weekends)

## v1 Requirements

The v0.1 milestone. Each maps to roadmap phases. v0.5 (`holt doctor`) and v1.0 (orchestrator + Nak) are future milestones tracked in v2 below.

### Core — shim wrapper + timing + cache + supervision

- [ ] **CORE-01**: Shim binary wraps user's existing `statusLine.command` from `~/.claude/settings.json` and emits the wrapped script's stdout unchanged on the happy path
- [ ] **CORE-02**: Per-fire timing log appended to `~/.cache/holt/timings.jsonl` with duration, fork count, exit code, and stderr capture for every wrapped invocation
- [ ] **CORE-03**: Last-known-good TTL cache — render previous output instantly, recompute in background, replace on completion
- [ ] **CORE-04**: Configurable timeout + clean Unix process-group kill via `process-wrap` v9.1.0 `ProcessGroup::leader()` (setpgid + killpg) — verifies `setpgid` return value and falls back to libproc PPID-walk + per-PID SIGKILL if EPERM
- [ ] **CORE-05**: All spawned children pipe stdin/stdout/stderr (`Stdio::piped()` × 3) — never inherit parent TTY (SIGTTIN avoidance, hard constraint C1)
- [ ] **CORE-06**: Breach log appended to `~/.cache/holt/breaches.log` with full context (env, stdin JSON, stderr) when timing exceeds configurable threshold
- [ ] **CORE-07**: Sub-20ms cold-start overhead on Linux x86_64 and macOS arm64 (Windows budget separate at 40ms with Defender) — measured via `holt --self-bench` on first phase ship
- [ ] **CORE-08**: Defensive stdin JSON parse — `serde_json::from_slice` failures captured in breach log as parse-fail events; render falls through to last-known-good cache; never bubbles errors to user
- [ ] **CORE-09**: Render path never opens `breaches.log` or `timings.jsonl` for reading — these are write-only outputs of the supervisor (hard constraint C6, prevents render-storm-on-grow)
- [ ] **CORE-10**: `holt-render` crate has zero direct dependency on `holt-supervisor` crate — wrapped output is plumbed via function arg only (hard constraint C2, enforced in CI via `cargo tree`)

### Hooks — heartbeat write + install UX

- [ ] **HOOK-01**: Heartbeat hook subscribes to `PreToolUse`, `PostToolUse`, `Stop`, `Notification`, and `SessionStart` events; writes session JSON on every fire
- [ ] **HOOK-02**: Heartbeat path = `$XDG_RUNTIME_DIR/holt/sessions/<sid>.json` (Linux), `$TMPDIR/holt-$UID/sessions/<sid>.json` (macOS), with layered fallback chain to `~/.cache/holt/sessions/` if neither is writable (PITFALLS.md H4)
- [ ] **HOOK-03**: Atomic heartbeat write — tmp file in same directory (`<sid>.json.holt-tmp.<pid>`), `fsync(2)` on temp fd, then `rename(2)` — never tolerates EXDEV (hard constraint C5; PITFALLS.md H2)
- [ ] **HOOK-04**: Heartbeat populates `cwd_label` from CC stdin's `workspace.git_worktree` field when present (CC v2.1.98+); falls back to `cwd`-parse `<repo>/<branch>` when absent (FEATURES.md "New since 04-28" #2)
- [ ] **HOOK-05**: Heartbeat schema is exactly `schema_version: 1` per `docs/05-schemas.md` §1; includes `pid`, `started`, `updated`, `cwd`, `cwd_label`, `mode`, `current_tool`, `blocked_on` (writer always null at v0.1), `last_assistant_at`, `model_display`
- [ ] **HOOK-06**: Heartbeat embeds a `writer_version` field (semver string of the holt build that wrote it) for forward-compat (PITFALLS.md H8)
- [ ] **HOOK-07**: `holt install-hooks` reads `~/.claude/settings.json`, merges holt's hook entries non-destructively, writes back atomically with `.holt.bak` backup
- [ ] **HOOK-08**: `holt install-hooks --dry-run` prints the diff that would be applied; `--print` emits the JSON snippet for manual paste; both exit 0 without mutating settings.json
- [ ] **HOOK-09**: `holt install-hooks` acquires `fs2::FileExt::try_lock_exclusive()` on settings.json for the entire read-merge-write window; `fsync(2)` before `rename(2)` (hard constraint C3; PITFALLS.md H1, H12)
- [ ] **HOOK-10**: `holt install-hooks` round-trips JSONC (preserves user comments and key order in settings.json) — uses `jsonc-parser` v0.26+ CST in `holt-cli` only (hard constraint C4)
- [ ] **HOOK-11**: Reader (`holt-orchestrator::read_heartbeat`) treats stale-or-corrupt heartbeat as missing — never `unwrap()`, never panics; logs once per session per process (hard constraint C5)

### Distribution & Launch

- [ ] **DIST-01**: `dist` (formerly `cargo-dist`) v0.31.0 prebuilt binaries shipped on day one for Linux x64, macOS x64, macOS arm64, and Windows x64 (best-effort) — scaffold via `dist init`, config in `dist.toml` / `dist-workspace.toml`
- [ ] **DIST-02**: Homebrew tap (`<user>/holt`) auto-generated by `dist`; README leads with `brew install <user>/tap/holt` to bypass macOS Gatekeeper friction (PITFALLS.md H7)
- [ ] **DIST-03**: `cargo binstall holt` works from day one (binstall metadata in `Cargo.toml`)
- [ ] **DIST-04**: README leads with an asciinema/gif of the shim transparently wrapping a slow user statusLine — installation in three lines, working demo in ten seconds
- [ ] **DIST-05**: MSRV pinned to Rust 1.87, Edition 2024 (matches `process-wrap` 9.1.0 baseline)
- [ ] **DIST-06**: README clearly states v0.1 platform tier — Unix-tier-1, Windows best-effort — and links the trigger criteria for promoting Windows ([≥10 Windows-tagged issues OR a Windows contributor steps up])
- [ ] **DIST-07**: `CONTRIBUTING.md` already present at the repo root; no rewrite needed at v0.1; trigger-gating tags (`bug`, `feature`, `windows`, `pet`, `runtime`, `orchestrator`, `good first issue`, `help wanted`) configured on the GitHub repo before launch

## v2 Requirements

Deferred to future milestones. Tracked but not in current roadmap.

### Doctor (v0.5 — additive on v0.1 supervisor)

- **DOC-01**: `holt doctor` fires the configured script 20× under load
- **DOC-02**: `holt doctor` ranks fork count / network calls / FS bytes / p95 latency in a culprit table
- **DOC-03**: `holt doctor` produces output in <30 seconds against a fresh user's existing statusLine config
- **DOC-04**: `holt doctor --share` produces a redacted bug-report bundle (gated on breach-log format stability ≥2 releases)
- **DOC-05**: `holt doctor --first-run` Gatekeeper / quarantine check on macOS

### Orchestrator (v1.0 — multi-session)

- **ORCH-01**: Cross-session reader — every fire reads all heartbeat files in `$XDG_RUNTIME_DIR/holt/sessions/`; treats `mtime > 2 × refreshInterval` as stale
- **ORCH-02**: Attention-queue render — `[N/M waiting]` aggregate counter
- **ORCH-03**: Rotating peer-detail slot — most-attention-needing peer (waiting longest first, then wedged, then completed-and-idle, then most-recently-active)
- **ORCH-04**: Worktree label rendering — `<repo>/<branch>` derived from cwd or `workspace.git_worktree`; override via `HOLT_LABEL` env var
- **ORCH-05**: Aggregate burn-this-hour rollup across all live sessions (heartbeat already carries `burn_rate_usd_per_min`); explicitly aggregates sub-agent sessions (CC #48040 free win)
- **ORCH-06**: `holt peers` TUI sub-command — full grid drilldown (sessions × attributes); the bar stays primary, this is opt-in
- **ORCH-07**: Heartbeat schema rich fields — `current_tool`, `mode`, `context_pct_real`, `burn_rate_usd_per_min`, `last_assistant_at`, `model_display` — all populated by hook
- **ORCH-08**: PreCompact hook subscription added to heartbeat-writer (CC v2.1.105+) for precise compact-start/end detection
- **ORCH-09**: Stuck-loop detector via `PostToolUse.duration_ms` (CC v2.1.119+) — surfaces in heartbeat as `blocked_on: "stalled"`

### Pet (v1.0 — Nak as core feature)

- **PET-01**: Nak — 12-state ASCII vocabulary at fixed 5-cell width per `docs/04-pet.md` §3
- **PET-02**: Heartbeat-driven animation only (never tick-driven) — animations transition between frames only on PreToolUse / PostToolUse / Stop / Notification events
- **PET-03**: Default-on; opt-out via `--no-pet` install flag or `[pet] enabled = false` config
- **PET-04**: Naming on first install (default `Nak`); `holt pet rename` mutates name; rename history append-only; past memories preserve original name (`docs/05-schemas.md` §4)
- **PET-05**: Pet diary — `~/.local/share/holt/pet/<name>/diary.md` markdown chronicle, append-only; `holt pet diary` subcommand
- **PET-06**: Pet state JSON — `~/.local/state/holt/pet/<name>.json` per `docs/05-schemas.md` v1 schema; memory cap 200 events; archive to `<name>.archive.jsonl` after cap
- **PET-07**: Cross-pet friendship aggregation — co-alive heartbeats accumulate `hours` / `merges` / `exhaustions` per `(cwd_label)` peer; thresholds tunable in `~/.config/holt/config.toml`
- **PET-08**: Companion-dot rendering — peer count as trailing dots beside Nak
- **PET-09**: Rotating peer-pet detail in attention slot — `(•ω•) >> (>_<)@auth/feat`
- **PET-10**: Pet stakes from observable session state only (context %, burn rate, stall) — never from user-behavior decay across days (`docs/04-pet.md` §5.3)
- **PET-11**: Pet writes happen off the render path (only heartbeat hook reads pet state) — `holt-render` reads heartbeat, never `pet/<name>.json` (PITFALLS.md H10)

### v1.0 misc

- **MISC-01**: Autocompact buffer-math correction — `context_pct_real` derived correctly even when CC's official inputs are wrong; degrades gracefully if CC #52089 ships and exposes correct values directly (SUMMARY.md trigger-watch)
- **MISC-02**: Plan-mode vs execute-mode color flip — full-bar mode signal from `permissionMode` JSONL line (already shipping CC v2.1.119)

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Push notifications about pet/session state | Notification fatigue is the #1 mascot-app uninstall trigger ([MagicBell](https://www.magicbell.com/blog/alert-fatigue): 64% delete after ≥5/week). holt never pushes. |
| Speech bubbles / pet talking | Clippy's autopsy. Pet exists; doesn't narrate. (`docs/04-pet.md` §2) |
| Tick-driven animation | Hard architectural constraint. A still pet during expected activity *is* the wedged-session signal. |
| Plugin / extension runtime at v1.0 | Curated presets via PR; sandbox runtime gated on ≥30 community presets requesting unmappable capabilities (post-1.0). |
| Telemetry / analytics | Trust is the product. Trigger-gating runs through GitHub issue counts only. |
| Cross-machine pet sync at v1.0 | Same-machine first; sync is 1.x stretch behind explicit `--sync` opt-in. |
| Separate dashboard / TUI app | holt is a statusLine. `holt peers` is a sub-command, not a separate product. |
| Pokemon / copyrighted art | krabby is one C&D away from ruin. Original ASCII otter only. |
| Render holt's own segments at v0.1 | Crowded category (ccstatusline, CCometixLine, ccburn, usage-bar, ccusage). Wedge is runtime hygiene, not widgets. Native rendering is a v0.5+ trigger. |
| TOML config language at v0.1 | Starship pattern: TOML at v0.13, four months in. Sane defaults + env vars + CLI flags until users complain. |
| Async runtime (tokio etc.) at v0.1 | Unjustified for current scope; sync stdlib + threads. Audit transitive `tokio` pull-through (`cargo tree -i tokio` discipline). |
| `simd-json` / `figment` | Pessimization for small JSON inputs. Stock `serde_json` + `toml` is sub-millisecond. |
| Linux arm64 binary at v0.1 | Add to dist matrix at first .1 release. |
| Code signing (macOS notarization, Windows EV cert) | Gatekeeper warning is acceptable friction at MVP; Brew install bypasses it. Trigger-gated to 1.0 promise once friction blocks ≥5 issues. |
| Windows JobObject + ConPTY correctness | Unix-tier-1 at MVP. Windows runs but documented best-effort. Trigger: ≥10 Windows-tagged issues OR a Windows contributor. |
| OSC8 deep-links + Nerd Fonts at v0.1 | Old-terminal corruption risk and width-math tar pit. ASCII-default; opt-in once a width-detection probe ships at 1.x. |
| Effort/thinking pill rendering at v0.1 | Field shipped (CC v2.1.119) but only useful when holt renders its own segments — ship with native rendering trigger. |
| Pre-launch outreach | Ship and let issues land. CONTRIBUTING.md tags route reports cleanly. |
| Daemon over Unix socket | Files-on-disk + hooks suffices for ≤8 sessions. Daemon is 1.x optimization gated on ≥3 issues reporting ≥10-session lag. |
| User-behavior pet decay across days | Clippy emotional-manipulation pattern. Pet state reflects observable session state only (`docs/04-pet.md` §5.3). |
